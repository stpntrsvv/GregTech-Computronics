# GregTech: Computronics

GregTech CEu addon for Minecraft 1.20.1 and Forge.

## Current content

- `gtcomputronics:punch_card`
- GregTech: Computronics creative tab
- Temporary punch card recipe: `minecraft:paper` -> `gtcomputronics:punch_card`

## Development

Build the project:

```powershell
.\gradlew.bat build
```

Run formatting:

```powershell
.\gradlew.bat spotlessApply
```
